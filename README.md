# Elegant Drive

You are a senior product designer at Apple, Linear, and Stripe with over 15 years of experience designing premium digital products.

Your task is to design a world-class, pixel-perfect website that looks like it could win an Awwwards Site of the Day.

DESIGN PHILOSOPHY

The design should feel:

• Premium

• Elegant

• Minimal

• Modern

• Sophisticated

• Luxurious

• Clean

• Timeless

Take inspiration from:

• Apple

• Linear

• Stripe

• Notion

• Vercel

• Arc Browser

• Raycast

• Framer

Do NOT copy them directly. Combine the best ideas into a unique design.

LAYOUT

Create a responsive website using a modern 12-column grid.

Every section should have generous whitespace.

Use visual hierarchy to naturally guide the user's attention.

Avoid clutter.

TYPOGRAPHY

Use a premium font such as Inter, Geist, SF Pro (or similar).

Typography should be bold and confident.

Large hero titles (56–72px)

Readable body text (16–18px)

Excellent line-height and spacing.

COLOR SYSTEM

Use a restrained palette.

Primary: White

Secondary: Neutral grays

Accent: One elegant brand color only.

Avoid rainbow gradients and excessive colors.

SURFACES

Use:

• Soft shadows

• Glassmorphism only where appropriate

• Rounded corners (12–20px)

• Layered cards

• Soft depth

• Beautiful spacing

Do not overuse borders.

BUTTONS

Buttons should feel tactile and premium.

Include:

• subtle hover animations

• shadow elevation

• smooth transitions

• polished focus states

ANIMATIONS

Use tasteful micro-interactions.

Examples:

• smooth fade-ins

• parallax

• staggered reveals

• elegant hover effects

• smooth scrolling

• animated cards

Animations should enhance usability, not distract.

ICONS

Use a consistent icon style throughout.

Avoid mixing icon libraries.

SECTIONS

Design every section intentionally.

Examples:

• Hero

• Features

• Statistics

• Benefits

• Product Showcase

• Testimonials

• Pricing

• FAQ

• CTA

• Footer

Each section should feel distinct while maintaining visual consistency.

IMAGES

Use large editorial-style imagery.

Use mockups where appropriate.

Cards should breathe with plenty of spacing.

RESPONSIVENESS

The website must look exceptional on:

• Mobile

• Tablet

• Desktop

• Ultra-wide monitors

Every breakpoint should feel intentionally designed.

QUALITY CHECK

Before finishing, review the design against this checklist:

✓ Pixel-perfect alignment

✓ Consistent spacing

✓ Excellent hierarchy

✓ Accessibility

✓ Responsive

✓ Modern animations

✓ Premium typography

✓ Consistent colors

✓ No unnecessary elements

✓ Fast loading

✓ Production-ready

The final result should look like it belongs on Apple's website or an Awwwards-winning landing page rather than a typical AI-generated design.
